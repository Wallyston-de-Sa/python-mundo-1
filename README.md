# 🐍 Python Mundo 1

Repositório desenvolvido durante o **Mundo 1 do curso de Python**, reunindo aulas, exercícios, desafios e aplicações práticas desenvolvidas durante minha evolução na linguagem.

Este repositório representa minha primeira etapa de aprendizado em Python, desde os primeiros comandos até a construção de pequenos programas utilizando os fundamentos da linguagem e também utilizando o git e github.

---

## 📚 Sobre o curso

O **Mundo 1** foi minha etapa de construção da base em Python.

Durante o módulo, pratiquei conceitos fundamentais por meio das aulas, exercícios e desafios propostos pelo curso, além de aplicar os conhecimentos em pequenas missões relacionadas ao projeto **HotelHub**.

O objetivo desta etapa foi desenvolver uma base sólida de programação e começar a transformar os conceitos estudados em código.

---

## 🎯 Objetivos

- Aprender os fundamentos da linguagem Python.
- Desenvolver lógica de programação.
- Praticar através de exercícios e desafios.
- Aprender a organizar meus códigos.
- Criar o hábito de documentar minha evolução.
- Utilizar Git e GitHub durante os estudos.
- Construir uma base sólida para projetos futuros.
- Aplicar os conhecimentos aprendidos no desenvolvimento do HotelHub.

### 📚 Aulas

A pasta `aulas/` reúne os materiais e anotações desenvolvidos durante as aulas do Mundo 1.

Cada arquivo em Markdown registra os principais conceitos estudados, servindo como material de consulta durante minha evolução.

### 🧩 Desafios do curso

A pasta `desafios/curso/` reúne os exercícios e desafios realizados durante o curso.

Os desafios foram utilizados para colocar em prática os conteúdos apresentados nas aulas e desenvolver minha capacidade de resolver problemas utilizando Python.

### 🏨 HotelHub

A pasta `desafios/hotelhub/` reúne as missões desenvolvidas para aplicar os conhecimentos do curso em um projeto relacionado à área de hotelaria.

O HotelHub começou como pequenas aplicações e será desenvolvido gradualmente conforme novos conhecimentos forem adquiridos.

---

## 🏨 HotelHub

O **HotelHub** é um projeto paralelo criado durante meus estudos de Python.

A proposta é transformar os conhecimentos aprendidos ao longo do curso em funcionalidades relacionadas à gestão de pousadas e hotéis.

Neste primeiro momento, o projeto está sendo desenvolvido através de pequenas missões práticas. A ideia é evoluí-lo junto com meu aprendizado, aumentando sua complexidade conforme avanço nos próximos módulos.
