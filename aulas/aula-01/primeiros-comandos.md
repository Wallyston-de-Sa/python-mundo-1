# Aula 01 - Primeiros Comandos em Python

## Objetivo da aula

Aprender a utilizar os primeiros comandos da linguagem Python.

---

## Comando `print()`

O comando `print()` é utilizado para exibir informações na tela.

### Exemplos

```python
print("Olá, mundo!")
print(7 + 4)
print("7" + "4")
```

**Saída:**

```
Olá, mundo!
11
74
```

**Observação:**

- `7 + 4` realiza uma soma.
- `"7" + "4"` junta dois textos (strings), resultando em `74`.

---

## Variáveis

As variáveis são utilizadas para armazenar informações.

### Exemplo

```python
nome = "Wallyston"
idade = 23
peso = 74.5

print(nome, idade, peso)
```

---

## Entrada de dados com `input()`

O comando `input()` permite receber informações digitadas pelo usuário.

### Exemplo

```python
nome = input("Qual é o seu nome? ")
idade = input("Quantos anos você tem? ")
peso = input("Qual é o seu peso? ")

print(nome, idade, peso)
```

---

- Como criar variáveis.
- Como solicitar informações ao usuário utilizando `input()`.
